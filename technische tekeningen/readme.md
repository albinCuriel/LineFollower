# Technische tekeningen

| Map | Inhoud |
|---|---|
| [elektronisch](elektronisch/readme.md) | elektrisch schema (KiCad + PDF), boormal, bekabelingsplan, draadlijst |
| [mechanisch](mechanisch/readme.md) | 3D-model met de maten van de bestelde onderdelen, samenstellingstekening |

Alles is gemaakt met scripts. Het bekabelingsplan en het 3D-model gebruiken dezelfde posities en dezelfde onderdelen. Verander je iets, pas dan het script aan en draai het opnieuw: tekening en tabel blijven zo altijd gelijk.
