# 3D-model

Gemaakt door [model_linefollower.py](../model_linefollower.py). Assen: X = rijrichting, Y = links, Z = omhoog. Oorsprong = midden wielas op de grond. Eenheid: mm.

| Bestand | Inhoud |
|---|---|
| `linefollower_assembly.step` | volledige samenstelling, te openen in SOLIDWORKS, Fusion 360, FreeCAD of KiCad |
| `*.stl` | elk onderdeel apart. Klik op een STL op GitHub om hem in 3D te bekijken en te draaien |

| STL | Onderdeel |
|---|---|
| [gaatjesprint.stl](gaatjesprint.stl) | chassis 120 × 90 × 1,6 |
| [ESP32-S3_devkit.stl](ESP32-S3_devkit.stl) | ESP32-S3 devkit met pinnen |
| [QTR-8A.stl](QTR-8A.stl) | sensorarray, sensoren naar beneden |
| [M2_bevestiging_sensor.stl](M2_bevestiging_sensor.stl) | 2× M2×25 voor de sensorhoogte |
| [TB6612FNG.stl](TB6612FNG.stl) | H-brug |
| [buck_CN3903_3V3.stl](buck_CN3903_3V3.stl) | 3,3 V-regelaar |
| [LiPo_2S_450mAh.stl](LiPo_2S_450mAh.stl) | batterij |

| [beugel_links.stl](beugel_links.stl), [beugel_rechts.stl](beugel_rechts.stl) | Pololu motorbeugels |
