# Finale code

Hier komt de finale linefollower-code, zodra het [basisprogramma](../basis/readme.md) en de [proof of concepts](../proof%20of%20concepts/readme.md) op de robot werken.

Gepland:
- kalibratie zwart/wit per sensor, normalisatie, interpolatie van de lijnpositie
- PID-regeling op de lijnpositie
- snelheidsregeling per wiel met de encoders
- boost/brake: sneller op rechte stukken, kort remmen voor een bocht
- live meetwaarden en instellingen via wifi, opgeslagen in het flashgeheugen
