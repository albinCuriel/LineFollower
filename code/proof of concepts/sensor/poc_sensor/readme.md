# poc_sensor

Arduino-sketchmap. Open `poc_sensor.ino` in de Arduino IDE of compileer met

```
arduino-cli compile --fqbn esp32:esp32:esp32s3 .
```

`board.h` is een kopie van [code/board.h](../../../board.h) (Arduino neemt enkel bestanden uit de eigen sketchmap mee).
Uitleg en testresultaat: [readme van deze proof of concept](../readme.md).
